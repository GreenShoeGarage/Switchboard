# Web workbench

The web application lives in the repository's `app/` directory and uses the
Next.js App Router. This directory preserves the top-level repository boundary
and can hold web-only packages if the application is split into a workspace later.

The current workbench is implemented in:

- `app/page.tsx`
- `app/switchboard-workbench.tsx`
- `app/layout.tsx`
- `app/globals.css`
- `app/api/`
